Layer boundary fixes

Why start with god components? They block all other improvements. You can't extract a page shell or relocate mappers while MappingTab.tsx is 1,170 lines. Decomposition creates the seams that the other candidates need.

Why factories next? Once pages are decomposed, the API module and hook scaffolding duplication becomes the biggest maintenance burden. A factory removes ~550 lines of identical code and makes adding new entities trivial.

Layer fixes last because they're lower risk but require the other refactors to be stable first. The infrastructure→application coupling is a latent risk, not an active blocker.
