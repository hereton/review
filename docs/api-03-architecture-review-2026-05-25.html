Exact pattern repeated 8 times:

func handleXError(c *gin.Context, err error) {
    var ve domain.ErrValidation
    switch {
    case errors.As(err, &ve):
        c.JSON(http.StatusBadRequest, domain.Error(err.Error()))
    case errors.Is(err, domain.ErrNotFound):
        c.JSON(http.StatusNotFound, domain.Error("..."))
    case errors.Is(err, domain.ErrConflict):
        c.JSON(http.StatusConflict, domain.Error("..."))
    default:
        slog.Error("...", "error", err)
        c.JSON(http.StatusInternalServerError, domain.Error("..."))
    }
}

Problem: Shallow modules — each handler re-implements the same error-to-HTTP mapping interface, giving callers no leverage from the domain error vocabulary.

Solution: Extract a shared HandleError(c, err, ErrorMap) where ErrorMap maps domain sentinels to HTTP status + Thai message. Each handler registers only its domain-specific entries.

~-120 lines removed single error seam new modules auto-covered consistent HTTP mapping

Top Recommendation

Start with Candidate 4 (isUniqueViolation helper relocation) — it's a 5-minute fix with zero risk that immediately improves locality.

Then Candidate 5 (delete unused permission.go) — another 5-minute fix. Removes dead code and eliminates confusion about which authz path to use.

Then Candidate 1 (handler error mapping) — highest impact (~120 lines removed, single error seam). This is the Strong candidate and creates the deepest module improvement. Do it before adding new handler modules.

Then Candidate 2 (query builder) — addresses the most dangerous long-term risk (4 diverging WHERE approaches). Worth doing before adding new repositories.

Candidate 3 (request parsing) can wait until the next time handlers are modified, as it's a convenience improvement rather than a correctness risk.

Recommended order:

  1. Spec Move isUniqueViolation → helpers.go
  2. Spec Delete unused permission.go
  3. Strong Extract shared HandleError + ErrorMap
  4. Worth Introduce QueryBuilder for WHERE/ORDER BY
  5. Worth Extract ParseID / Bind[T] / MustActor helpers
