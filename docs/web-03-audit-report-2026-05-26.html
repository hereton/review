▶ Anti-patterns 1
High CRUD hook duplication

All 11 feature hooks repeat identical TanStack Query mutation patterns: useMutation + qc.invalidateQueries + pushToast error. A generic factory could eliminate ~60% of hook code.

// useRoles.ts
export function useCreateRole(appCode: string) {
  const qc = useQueryClient();
  return useMutation({
    mutationFn: (payload: CreateRolePayload) => api.role.create(appCode, payload),
    onSuccess: () => qc.invalidateQueries({ queryKey: roleKeys.all(appCode) }),
    onError: (err: Error) => pushToast({ title: 'เกิดข้อผิดพลาด', desc: err.message, variant: 'error' }),
  });
}
// usePermissions.ts — identical pattern, different entity
▶ Healthy Patterns 4
TanStack Query for server state — Proper useQuery/useMutation with cache invalidation. 30s stale time, retry once (except 401/403), no refetch on window focus.
Feature-scoped hook placement — Hooks in features/*/hooks/ directory. Clear co-location of data-fetching logic with domain.
useTableState abstraction — Generic useTableState hook for table sorting, pagination, filter reset. Reused across pages.
Query key factories — roleKeys.all(appCode), permissionKeys.all(appCode) pattern for structured cache invalidation.
