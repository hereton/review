Top Recommendation

Start with Candidate 1: Data-Fetch Hook Factory. It provides the highest leverage — touching every data-access hook in the project and removing ~2,000 lines of boilerplate. All other candidates become easier once the hook layer has a clean, thin interface.

Recommended order

1 Hook Factory → 3 Mappers + 2 Date Format → 4 Filters → 5 Modals → 6 Combobox → 7 Auth

Candidates 1 + 2 can run in parallel — independent, both strong.

Candidate 3 builds on 1 by standardizing the mapper layer inside each thin hook.

Candidates 4 + 5 depend on stable hook interfaces from 1.

Candidate 6 is UI-level, independent of data layer.

Candidate 7 is best done last when component structure is cleaner.

Estimated total impact: ~4,000 lines removed across 35+ files.
