Presentation Layer

▶ Anti-patterns 23
Critical God Component

pages/tabs/MappingTab.tsx (1,036 lines) and pages/EmployeesPage.tsx (978 lines) handle data fetching, filtering, validation, transformation, and rendering in single files.

Critical Direct API Call

pages/EmployeesPage.tsx uses raw fetch() for export, bypassing the Application layer entirely.

High Excessive Inline Styles

EmployeesPage.tsx (50+ inline style={{}} objects), DelegationFormModal.tsx (20+), DeleteRoleModal.tsx (15+). Should use Tailwind classes or CSS modules.

High Inline Business Logic

Hex color validation and luminance calculation in EmployeesPage.tsx, error-code mapping in ApplicationsPage.tsx, date formatting in RolesTab.tsx — all should live in Domain layer.

Medium Prop Drilling

App.tsx passes 8 props to ApplicationsPage. SubSidebar accepts 12 props. No context provider to share state.

Medium Hardcoded Mock Data

AuditLogsPage.tsx (27 mock entries) and SettingsPage.tsx (mock sync logs) embed mock data directly in components.

Application Layer

▶ Anti-patterns 8
High Duplicated CRUD Hook Boilerplate

15+ hooks repeat identical useState + useEffect + cancelled flag + useCallback refetch pattern. ~60% of CRUD hook code is boilerplate with only URL and type mapping varying. Affected: usePermissions, useRoles, useApplications, useAbacAssignments, useOUMappings, useManualAssignments.

High DOM Manipulation in Hook

useExportManageUsers.ts creates document.createElement('a') for file download — a Presentation concern leaking into Application layer.

Medium Duplicated Date Formatting

useOUMappings.ts and useManualAssignments.ts duplicate THAI_MONTHS_SHORT array and isoDateTimeToThai function that already exists in lib/dateFormat.ts.

Medium Duplicated snake_case Mappers

19 hooks each define inline fromApi/fromApiResponse functions converting snake_case API responses to camelCase. Each mapping is unique per entity but the scaffolding is identical.

Medium Overlapping State (Delegation)

useDelegations.ts (RBAC, 97 lines) and useAbacDelegations.ts (ABAC, 61 lines) manage the same entity shape with different API endpoints.

Medium Reverse Dependency

useAppOptions.ts and useRoleOptions.ts import SelectOption type from components/SearchableSelect.tsx — Application depends on Presentation.

▶ Healthy Patterns 7
Consistent Cancellation — 20/34 hooks use the let cancelled = false pattern to prevent state updates after unmount.
Debounce at Hook Layer — 7 hooks debounce search queries (300ms) with useRef timer cleanup.
useTableState Abstraction — Generic <TCol> table state hook reused across pages. Good depth at a narrow interface.
Hook Composition — useOuFilters composes three nested useOUOptions hooks for cascading filter behavior.
In-Memory Caching — useRoleOptions uses module-level cache with 30s TTL to reduce redundant network calls.

Domain Layer

▶ Anti-patterns 7
Critical God File: types.ts (708 lines, 53 types, 12 domain concepts)

All domain types in a single file: App, Role, Permission, ABAC entities, Employee, Delegation, ManageUser, OU options — plus their API response counterparts. 4.7x over the 150-line threshold.

High Mock Data in Production Paths

App.tsx imports ROLES, PERMISSIONS, AUTO_MAPPINGS from mock.ts for sidebar counts. DeleteRoleModal.tsx uses MOCK_IMPACTED_USERS. Production renders fake data.

Medium Mixed API + Domain Types

Domain types (camelCase: AppRole) interleaved with API DTOs (snake_case: RoleResponse). The same file defines both layers of types.

Medium Scattered Entity Definitions

AppRole defined in hooks/useRoles.ts, AppPermission in hooks/usePermissions.ts — core domain types owned by Application layer instead of Domain.

▶ Healthy Patterns 5
Pure Domain Layer — types.ts has zero imports — no side effects, no async, no DOM. Clean.
Discriminated Unions — Status fields use 'active' | 'inactive' | 'draft' consistently. Type-safe state modeling.
Consistent Pagination Wrappers — *ListResponse pattern used consistently across all paginated endpoints.

Infrastructure Layer

▶ Anti-patterns 8
Critical Hardcoded Production URL

lib/api.ts:1 — Fallback URL https://permission-center-api04-...run.app couples deployments to a specific Cloud Run instance.

Critical DEV_TOKEN Auth Bypass

Both api.ts and auth.ts check VITE_DEV_TOKEN — if this env var leaks to production builds, authentication is bypassed entirely.

Medium No Retry, Timeout, or Caching

Fetch wrapper has no retry mechanism, no request timeout, and no caching/deduplication. Multiple components mounting simultaneously fire identical API requests.

Medium Presentation Concern in Infrastructure

toast.ts exports a useToastStore() React hook — UI state management in the infrastructure layer.

▶ Healthy Patterns 6
Typed API Client — api.get<T>, api.post<T>, etc. preserve type safety through the request/response cycle.
Consistent Error Handling — All errors converted to ApiError with localized Thai messages.
JWT Adapter — Clean JWT decode without external library dependency.
Configuration as Data — appMenus.ts defines menu items as constant arrays separate from logic.
▶ Metric Violations 1

api.ts: 5 methods — at threshold but acceptable since each delegates to the same request() function.

Problem: Each hook defines its own fromApi mapper converting snake_case API responses to camelCase domain objects. The scaffolding is identical across 19 hooks but each mapping is entity-specific.

Solution: Co-locate mappers with their domain type files (after Candidate 3). Create a generic mapKeys utility for simple cases, keep explicit mappers for complex transformations. Reduces each hook by 15-40 lines.

Top Recommendation

Start with: Candidate 1 (CRUD Hook Factory)

The CRUD hook factory addresses the highest volume of duplication (~1,200 lines across 15+ hooks) and creates a deep module that all future hooks benefit from. It also establishes the infrastructure for Candidates 4 (date formatting) and 7 (mappers) since those concerns can be built into the factory's configuration interface.

Recommended Order

  1. Candidate 4 — Deduplicate date formatting (quick win, zero risk)
  2. Candidate 3 — Split types.ts (enables better imports for next steps)
  3. Candidate 1 — CRUD hook factory (highest impact)
  4. Candidate 2 — ConfirmActionModal (second highest impact)
  5. Candidate 6 — Delete V1/V2 duplicates (cleanup)
  6. Candidate 5 — Remove mock data from production (needs API endpoints)
  7. Candidate 7 — Extract mappers (can be folded into Candidate 1)

Layer to Start With: Infrastructure

Infrastructure changes (lib/) have the smallest blast radius and highest leverage. The CRUD hook factory extends lib/api.ts with a configuration layer, giving depth at the seam between Application and Infrastructure. No Presentation files need to change.
