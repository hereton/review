7. Error Handling & Response Format

✓
Domain error hierarchy with 60+ sentinel errors

Thai user-facing messages in domain/errors.go. Machine-readable codes via domain.ErrorWithCode(). Validation errors include field-level detail via ErrValidation struct.

✓
Handler-level error mapping with per-domain mappers

Each handler group has its own error mapper (handleAppError, handleAssignmentError, handleEvaluateError) that maps domain errors to HTTP status codes.

⚠
Inconsistent error wrapping in usecase layer

application_usecase.go returns raw err without context. assignment_usecase.go wraps with fmt.Errorf("context: %w", err). Should be consistent across all usecases.

✓
Structured logging with slog

All errors logged with structured key-value pairs. Unexpected errors logged at Error level, expected domain errors at Warn.
