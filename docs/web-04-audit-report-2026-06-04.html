Top 3 Critical Findings

1. Zero unit test coverage
No unit tests exist anywhere in src/. Only 2 Playwright E2E spec files under tests/e2e/. Any refactoring risks silent regressions.
2. 1,081 inline styles overwhelming maintainability
style={{}} appears 1,081 times across the codebase. Inline styles bypass Tailwind, can't be overridden by design tokens, and make responsive adjustments extremely difficult.
3. Docker runs dev server in production
CMD ["sh", "-c", "npm run dev -- --host 0.0.0.0 --port ${PORT}"] — no production build step. Vite dev server is not optimized, not minified, and exposes source maps in production.

Top 3 Quick Wins

1. Fix Dockerfile to use production build
Add npm run build step + serve with serve or nginx. ~30 min effort, immediate production perf improvement.
2. Add React Router for navigation
Replace state-based section/subItem navigation with React Router. Enables deep linking, browser back/forward, and URL sharing.
3. Remove mock data from production imports
App.tsx:10 imports ROLES, PERMISSIONS, AUTO_MAPPINGS from mock.ts and uses them in sidebar counts. Switch to real API data.

Manual fetch pattern (useState + useEffect) instead of TanStack Query. Every hook reimplements loading/error/caching/refetch logic. No cache sharing, no background refetch, no stale-while-revalidate.

High

CRUD hook boilerplate duplication — many hooks follow identical patterns (list, create, update, delete) with only the API path differing. Could be a single generic useCrud<T>(basePath) hook.

5. Package Recommendations

Area Current Recommended Confidence Why
Data Fetching Manual useState+useEffect @tanstack/react-query v5 Strong Eliminates 36 hooks of boilerplate. Adds caching, background refetch, stale-while-revalidate, and optimistic updates.
Routing State-based (no router) react-router v7 Strong Enables deep linking, browser history, URL params. Essential for any multi-page SPA.
Forms Manual useState per field react-hook-form + zod Strong Replaces manual validation in 24 modals. Schema-based validation with TypeScript inference.
State Management useState only zustand v5 Strong Minimal API, no boilerplate. Perfect for selected app, navigation state, user preferences.
Unit Testing None (Playwright E2E only) vitest + @testing-library/react Strong Vite-native test runner. Zero config. Add vitest to vite.config.ts and start testing hooks/components.
